# MONDAY（マンデー）— 通常待機姿

AIバーチャルオフィスのキャラクター MONDAY の待機姿です。確定キャラクターシートの色、輪郭、顔、ネクタイに合わせ、コードだけで描いたベクター作画です。

| ファイル | 内容 |
|---|---|
| `monday_idle.png` | 本番用。1024×1024 RGBA、背景は完全透過。正面・全身・中央配置で、四辺に約15〜19%の透明余白 |
| `monday_idle.svg` | 同じ絵のベクター版。拡大しても劣化しません |
| `parts/*.png` | Web側で動かすためのレイヤー（すべて1024×1024で位置合わせ済み、上に重ねるだけ）。水たまり、本体、目（開き・半目・閉じ）、口、ネクタイ |
| `monday_idle_loop.webp` | 待機ループのプレビュー（2秒、24fps、512px、透過）。呼吸、まばたき、目線のゆらぎ、ネクタイのゆれ |
| `demo.html` | parts を CSS だけで動かす最小構成の見本 |
| `monday.py` | 生成スクリプト。`python3 monday.py` で PNG と SVG、`--all` を付けると parts とループも出力 |

## Web で動かすときの基準点
- 床（伸縮の基準点）：y = 756px（上から73.8%）。`transform-origin: 50% 73.8%` を指定すると、床に接したまま伸び縮みします。
- ネクタイの結び目（回転の中心）：(512, 596)px。
- 正方形のまま 1/16（64px）程度まで縮めても、顔が読み取れることを確認済みです。

ID カードなどの小物は、指定どおり描いていません。
